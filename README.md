## 04. LOCAL REPRODUCTION RUNTIME

This portfolio is built on standard Next.js and Tailwind CSS with strict TypeScript type-checking.

### Prerequisites
- Node.js `>= 20.x`
- Corepack enabled (`pnpm >= 9.x`)

### Execution Commands

```bash
# Clone the repository
git clone https://github.com/RizalSwikey/my-portofolio.git
cd my-portofolio

# Install locked dependencies
pnpm install

# Start local workstation development server
pnpm dev

# Typecheck and assemble production bundle
pnpm build

# Serve compiled production artifact locally
pnpm start
```
